# Code of Conduct / 行为准则

TravelKit-AI is an open source project for agent instructions around flight search, booking, payment, refund, change, and order workflows. We want issues, discussions, and pull requests to stay useful, respectful, and safe.

TravelKit-AI 是围绕航班搜索、预订、支付、退票、改签和订单流程的 agent 指令开源项目。我们希望 Issue、Discussion 和 Pull Request 保持有用、尊重和安全。

## Expected Behavior / 期望行为

- Be respectful and constructive when reporting issues or reviewing pull requests.
- Keep discussions focused on the project, user workflows, documentation, and safety.
- Use mock data only when describing flight, passenger, order, payment, refund, or change examples.
- Help maintainers protect user privacy and hidden TravelKit MCP fields.

- 反馈问题或 review PR 时保持尊重和建设性。
- 讨论应聚焦项目、用户流程、文档和安全。
- 描述航班、乘客、订单、支付、退票或改签示例时仅使用模拟数据。
- 协助维护者保护用户隐私和 TravelKit MCP 隐藏字段。

## Unacceptable Behavior / 不可接受行为

- Harassment, threats, insults, discriminatory language, or personal attacks.
- Publishing real credentials, API keys, passenger data, order data, ticket numbers, itinerary files, production logs, exploit details, or raw MCP responses containing sensitive data.
- Pressuring contributors or maintainers to expose private information or bypass confirmation and safety rules.
- Repeated off-topic, spam, or bad-faith participation.

- 骚扰、威胁、侮辱、歧视性语言或人身攻击。
- 发布真实凭证、API key、乘客信息、订单信息、票号、行程单、生产日志、漏洞利用细节，或包含敏感信息的 raw MCP 返回。
- 要求贡献者或维护者暴露隐私信息，或绕过确认和安全规则。
- 反复偏题、刷屏或恶意参与。

## Enforcement / 执行方式

Maintainers may edit or remove unsafe content, close issues or pull requests, limit participation, or report abuse to GitHub when needed. Security-sensitive reports should follow [SECURITY.md](SECURITY.md).

维护者可以在必要时编辑或移除不安全内容、关闭 Issue 或 Pull Request、限制参与，或向 GitHub 报告滥用行为。安全敏感问题请遵循 [SECURITY.md](SECURITY.md)。
